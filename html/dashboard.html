Cài đặt đồng bộ Google Sheet

Mỗi lần bấm Đồng bộ Google Sheet, danh sách hiện tại sẽ được ghi đè vào 2 trang tính Nguoi tham du và Trung thuong (tự tạo nếu chưa có).

1 Tạo Google Sheet và mở Apps Script
  1. Tạo một Google Sheet mới tại sheets.new (hoặc mở Sheet có sẵn).
  2. Trên thanh menu chọn Tiện ích mở rộng → Apps Script (Extensions → Apps Script).
2 Dán code
  1. Xoá hết code mặc định trong file Code.gs.
  2. Bấm Sao chép code bên dưới rồi dán vào, bấm Lưu (biểu tượng đĩa mềm).
3 Triển khai thành Ứng dụng web
  1. Bấm Triển khai → Tùy chọn triển khai mới (Deploy → New deployment).
  2. Bấm biểu tượng bánh răng, chọn Ứng dụng web (Web app).
  3. Thực thi dưới dạng: Tôi · Người có quyền truy cập: Bất kỳ ai (Anyone).
  4. Bấm Triển khai và cấp quyền cho tài khoản Google. Nếu Google cảnh báo, chọn Advanced → Go to … (unsafe) — đây là script của chính bạn.
  5. Sao chép URL ứng dụng web (kết thúc bằng /exec).
4 Dán URL vào đây
Đang dùng: (chưa cấu hình) Xoá URL đã lưu

URL được lưu trong trình duyệt này. Dùng máy hoặc trình duyệt khác thì cần dán lại. Khi sửa code Apps Script, vào Triển khai → Quản lý các bản triển khai → Chỉnh sửa → Phiên bản mới để URL giữ nguyên.
