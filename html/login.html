Đăng nhập quản trị
Chưa đặt mật khẩu admin. Làm một lần như sau:

Trên Cloudflare:

  1. Vào Workers & Pages → chọn Worker lucky-draw-dashboard.
  2. Settings → Variables and Secrets → Add.
  3. Type: Secret, Name: ADMIN_PASSWORD, Value: mật khẩu bạn muốn → Deploy.
  4. Tải lại trang này.

Chạy trên máy (npm start):

Tạo file .dev.vars ở thư mục dự án với nội dung ADMIN_PASSWORD=mat-khau-cua-ban rồi chạy lại.
